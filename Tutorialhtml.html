Encabezados

HTML utiliza seis niveles de encabezados, del <h1> al <h6>. Los encabezados más importantes tienen números más bajos.

<h2>Encabezado 2</h2>
<h3>Encabezado 3</h3>
<h4>Encabezado 4</h4>
<h5>Encabezado 5</h5>

Creación de un Formulario

Cajas de Texto

Las cajas de texto permiten al usuario ingresar datos. Se crean con la etiqueta <input type="text">.


        <form>
            <label for="nombre">Nombre:</label>
            <input type="text" id="nombre" name="nombre" placeholder="Escribe tu nombre">
        </form>

Cajas de Verificación

Las cajas de verificación permiten seleccionar una o más opciones. Se crean con la etiqueta <input type="checkbox">.


        <form>
            <p>Elige tus lenguajes favoritos:</p>
            <input type="checkbox" id="html" name="lenguaje" value="HTML">
            <label for="html">HTML</label><br>
            <input type="checkbox" id="css" name="lenguaje" value="CSS">
            <label for="css">CSS</label><br>
            <input type="checkbox" id="javascript" name="lenguaje" value="JavaScript">
            <label for="javascript">JavaScript</label>
        </form>

Textarea

El <textarea> se utiliza para ingresar texto en varias líneas.


        <form>
            <label for="comentarios">Comentarios:</label><br>
            <textarea id="comentarios" name="comentarios" rows="4" cols="50" placeholder="Escribe tus comentarios aquí..."></textarea>
        </form>
