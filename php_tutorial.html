¿Qué es PHP y para qué se utiliza?

PHP es un lenguaje de programación del lado del servidor diseñado para el desarrollo web, pero también se puede usar como un lenguaje de propósito general.


<?php
echo "¡Hola, mundo!";
?>

¿Qué programas requiero para poder utilizar PHP?

Para trabajar con PHP necesitas:

  • Un servidor web como Apache.
  • PHP instalado en tu máquina.
  • Un editor de texto como Visual Studio Code.

¿Qué es un servidor web?

Un servidor web es un programa que procesa solicitudes HTTP y sirve páginas web a los usuarios.

¿Qué es MySQL y qué diferencia hay entre SQL y MySQL?

SQL es un lenguaje de consulta estructurado para interactuar con bases de datos, mientras que MySQL es un sistema de gestión de bases de datos que utiliza SQL.

¿Cómo se usa PHP directamente en una página web?


<!DOCTYPE html>
<html>
<body>

<?php
echo "¡Esto es PHP embebido en HTML!";
?>

</body>
</html>

¿Qué son las variables y para qué sirven?

En PHP, las variables se definen con un signo de dólar ($) seguido del nombre de la variable.


<?php
$nombre = "Juan";
echo "Hola, " . $nombre;
?>

¿Qué es la variable string y qué función tiene?

Una variable string almacena cadenas de texto.


<?php
$mensaje = "Este es un string.";
echo $mensaje;
?>

¿Cómo se usa la estructura If en PHP y para qué sirve?


<?php
$edad = 18;
if ($edad >= 18) {
    echo "Eres mayor de edad.";
} else {
    echo "Eres menor de edad.";
}
?>

Repetidores en PHP

Los repetidores son estructuras para ejecutar código varias veces. Ejemplo: for, while, foreach.


<?php
for ($i = 1; $i <= 5; $i++) {
    echo "Número: $i<br>";
}
?>

¿Cómo crear un formulario y que la información se guarde en un bloc de notas?



<?php
$nombre = $_POST['nombre'];
$correo = $_POST['correo'];

// Escribir en un archivo llamado "datos.txt"
$file = fopen("datos.txt", "a");
fwrite($file, "Nombre: $nombre, Correo: $correo\n");
fclose($file);

?>

¿Cómo crear una base de datos en MySQL?

<?php
$conexion = new mysqli("localhost", "usuario", "contraseña");

// Crear base de datos
$sql = "CREATE DATABASE mi_base_de_datos";
if ($conexion->query($sql) === TRUE) {
    echo "Base de datos creada con éxito.";
} else {
    echo "Error: " . $conexion->error;
}
$conexion->close();
?>

¿Cómo crear una tabla en MySQL?

<?php
$conexion = new mysqli("localhost", "usuario", "contraseña", "mi_base_de_datos");

// Crear tabla
$sql = "CREATE TABLE usuarios (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nombre VARCHAR(50),
    correo VARCHAR(100)
)";
if ($conexion->query($sql) === TRUE) {
    echo "Tabla creada con éxito.";
} else {
    echo "Error: " . $conexion->error;
}
$conexion->close();
?>

¿Cómo crear un registro en MySQL?



<?php
$conexion = new mysqli("localhost", "usuario", "contraseña", "mi_base_de_datos");

$nombre = $_POST['nombre'];
$correo = $_POST['correo'];

// Insertar datos
$sql = "INSERT INTO usuarios (nombre, correo) VALUES ('$nombre', '$correo')";
if ($conexion->query($sql) === TRUE) {
    echo "Registro creado con éxito.";
} else {
    echo "Error: " . $conexion->error;
}
$conexion->close();
?>

¿Cómo crear un formulario y que la información se almacene en una base de datos?



<?php
$conexion = new mysqli("localhost", "usuario", "contraseña", "mi_base_de_datos");

$nombre = $_POST['nombre'];
$correo = $_POST['correo'];

$sql = $conexion->prepare("INSERT INTO usuarios (nombre, correo) VALUES (?, ?)");
$sql->bind_param("ss", $nombre, $correo);
if ($sql->execute()) {
    echo "Datos guardados en la base de datos.";
} else {
    echo "Error: " . $sql->error;
}
$conexion->close();
?>

¿Cómo crear un formulario que consulte información guardada en una base de datos?


<?php
$conexion = new mysqli("localhost", "usuario", "contraseña", "mi_base_de_datos");

$correo = $_POST['correo'];

$sql = "SELECT * FROM usuarios WHERE correo='$correo'";
$result = $conexion->query($sql);

if ($result->num_rows > 0) {
    while ($row = $result->fetch_assoc()) {
        echo "Nombre: " . $row['nombre'] . ", Correo: " . $row['correo'];
    }
} else {
    echo "No se encontraron resultados.";
}
$conexion->close();
?>
